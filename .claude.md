# Instructions Claude Code — Recto-versIA

## Début de session

Au lancement d'une nouvelle session :
1. Lire le fichier `.agent.md` à la racine du projet pour comprendre le contexte complet (stack, architecture, modèle de données, composants, conventions, roadmap)
2. Consulter les fichiers mémoire dans `.claude/projects/` pour s'appuyer sur l'expérience des sessions précédentes
3. Confirmer à l'utilisateur que le contexte est chargé et attendre ses instructions

## Fin de session

Avant de clôturer une session (quand l'utilisateur l'indique ou quand le travail est terminé) :
1. Mettre à jour `.agent.md` si des changements significatifs ont été apportés au projet :
   - Nouveaux composants, hooks, API routes ou collections Firestore
   - Modifications d'architecture ou de patterns existants
   - Fonctionnalités passées de la roadmap à "fonctionnel"
   - Nouvelles conventions ou points d'attention découverts
2. Mettre à jour les fichiers mémoire (`.claude/projects/.../memory/MEMORY.md`) si de nouveaux patterns stables ou préférences utilisateur ont été identifiés
3. Résumer les changements effectués durant la session
